# 实验性 SD / 串口设备树

这是在现有 V0.7 之上准备的独立实验文件。未经过真机启动验证。
它不会替换原始三文件补丁，也没有刷写到设备。

变更：

- 启用 I2C0 与 RK809，保留 V0.7 已移植的电源轨参数。
- 按本机 Android 设备树恢复 PMU IO-domain 电源映射。
- 启用 SDMMC0，限制在 3.3V、最高 50MHz，不进行 1.8V 切换。
- 启用 UART2，并加入串口别名和 stdout-path。
- 删除 CPU OPP 引用，避免在外置 CPU 调压器尚未移植时进行动态调频。
- eMMC、SDIO、显示等仍保持 V0.7 状态。

仍需验证：PMIC 电源操作、SD 卡检测、串口接线与波特率、原厂 U-Boot 的外部引导路径。
即使该 DTB 编译成功，也不能宣称 SD 镜像可启动。

编译时需要同时提供原始 `rk3566-tyc4a.dts` 与 Linux 6.18.63 的 Rockchip DTS 包含文件。
